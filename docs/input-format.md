# 入力CSV/TSVの仕様

生成コマンド（`generate_metadata_imports.py`）に渡す入力ファイルの仕様です。入力するメタデータは各自で収集・作成してください。エラーのある行が1行でもあると、既定では何も出力せずに停止します（[generate.md](generate.md#エラーのある行)）。

サンプルファイル: [sourcedata_sample.tsv](../sample/AXIES2025/sourcedata_sample.tsv)

## 列名

列名は、Item Type ZIP内のメタデータ項目名と一致させます。同じ列名が複数あるとエラーになります。次の例は、AXIES2025のサンプルItem Type（[ItemType_export_sample.zip](../sample/AXIES2025/config/ItemType_export_sample.zip)）に対応するものです。以下、「サンプル」はこのItem Typeを指します。

```csv
corpusid,Title,Title_g,Creator,PublicationYear_g
123,Main title,Alternative title,"['Alice', 'Bob']",2026-08-23T12:34:56
```

- Item Typeにない列は、`<path>:1: unknown column 'Titel' (did you mean 'Title'?) will be ignored` のように警告し、その列を使わずに生成します。`did you mean` の候補には、入力に列がないItem Typeの項目のうち、名前が似ているものが表示されます。識別用の列など、意図して含めている列であれば、この警告は無視して構いません。`--strict-columns` を指定すると、警告ではなくエラーで停止します。
- Item Typeの項目に対応する列がない場合は `missing column` と警告します。必須項目の列がない場合は、すべての行がエラーになります。

## 値の書き方

- セルの値の前後の空白は取り除かれます。空白だけのセルは空として扱います。
- 複数の値は、同名の列を並べずに1つのセルへ `"['Alice', 'Bob']"` のようなPython形式のリストで書きます。リストとして解釈されるのは、`[` で始まり `]` で終わるセルだけです。それ以外のセルは、そのまま1つの文字列になります。
- リストの要素は文字列にしてください。`[1.50]` のように数値を要素にするとエラーになるため、`"['1.50']"` と書きます。
- リストの空の要素（`''`、`None`）は取り除かれます。

複数の値を持てるのは、Item Typeで配列型の項目だけです（サンプルでは `Title`、`Creator`、`Contributor`、`Subject`、`Description`）。配列型でない項目に2つ以上の値を書くと、その行はエラーになります。

### 日付

日付の項目は、`YYYY-MM-DD`、`YYYY-MM`、`YYYY` のいずれかの形式で書きます。月・日は2桁にゼロ埋めしてください。時刻付きの値は日付に変換します。

| 入力 | 結果 |
|---|---|
| `2020-01-02T10:00:00` | `2020-01-02` |
| `2020-04-02T21:11:47+00:00`（UTCオフセット付き） | `2020-04-03`（設定の `date_timezone`、既定 `Asia/Tokyo` に換算） |
| `2020-1-2`、`2020/01/02`、`2020-02-30` | エラー |

WEKOでは `YYYY/MM/DD` などを受け付ける項目もありますが、このツールではエラーにします。

## 言語（`<列名>_lang` 列）

言語子項目（`*_language`）を持つ項目（サンプルでは `Title` と `Title_g`）は、`<列名>_lang` 列（例: `Title_lang`）で行ごとに言語コードを指定できます。セルが空の行には、設定の `default_languages` の値を使います。

- 複数の値を持つ項目では、`Title` に `"['T1', 'T2']"`、`Title_lang` に `"['ja', 'en']"` のように、値と同じ順・同じ数の言語を指定します。言語を1つだけ指定すると、すべての値に適用されます。
- 言語の数が値の数と合わない行は、エラーになります。
- 言語コードの妥当性は検査しません。WEKOが受け付けないコードは、インポート時に拒否されることがあります。

## タイトル

WEKOは、タイトルのないレコードを取り込みません。JPCOARのタイトル（`title`）にマッピングされた項目のうち、少なくとも1つに値と言語の両方が必要です。

- 値と言語の両方を持つタイトル項目が1つもない行は、エラーになります。
- どのタイトル項目にも言語が指定されていない場合（`default_languages` にも `<列名>_lang` 列にもない場合）は、生成を開始せずに停止します。

タイトルが空の行は、`--title-fallback` で埋めることもできます（[generate.md](generate.md#タイトルが空の行を埋める)）。

## その他の制限

- **制御文字**: タブ・改行（LF・CR）以外の制御文字（U+0000〜U+001F、U+007F）を含む行は、エラーになります（`<列名>_lang` 列と `--title-fallback` で指定した列を除き、Item Typeにない列は検査しません）。LLMで生成したデータによく見られます。リストのセルであれば[修復スクリプト](repair-control-chars.md)で直せます。それ以外は手作業で修正するか、`--skip-invalid-rows` で除外してください。
- **セルの長さ**: 1つの値は131,072文字までです。WEKOは、これを超える値を含むTSVのレコードを1件も取り込めないため、該当する行はエラーになります。
- **エラーの行番号**: ヘッダーを1行目とし、空行を除いて数えたレコード番号です。セル内の改行や空行があると、エディタ上の行番号と一致しないことがあります。
